# Other test images

Graphical images, mostly with smooth gradients and few details, plus a few photos.
Each has a palette config (`<name>.palettes.toml`) and reviewed outputs for 3, 7
and 16 inks (`<name>-out-<size>.png`), like the other golden-set folders.

The SVG drawings are PNG renders made by Wikimedia Commons; the photos are the
600 px previews from their source sites.
